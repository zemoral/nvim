## Custom Font Family
---
The goal of this project is to automate the build process for my preferred font family.

### Base Font Family
Source: https://recursive.design
Name: RecMonoIMorales
File: imorales.yaml
Commands:
- `make dependencies` To install dependencies
- `make config` To view configuration
- `make font` To generate the new font

### Dependencies
1. font: https://github.com/arrowtype/recursive-code-config.git
2. font editor: https://github.com/fontforge/fontforge/releases (app image)
3. nerd font patcher: https://github.com/ryanoasis/nerd-fonts/?tab=readme-ov-file#font-patcher
